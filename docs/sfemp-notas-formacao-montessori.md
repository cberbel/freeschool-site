# SFEMP — Notas: formação Montessori gravada e gratuita

Caderno de ideias. Só registro; feedback vem depois, quando o usuário pedir.

## Ideias do usuário

1. Fazer um curso de formação no padrão AMI ("AME" na fala).
2. Contratar um formador AMI experiente para dar o curso para a equipe.
3. Gravar o curso com produção de qualidade.
4. Disponibilizar a gravação inteira de graça para todo mundo.

## Pontos já levantados (resumo, para retomar no feedback)

- Formador AMI ativo provavelmente não pode gravar/distribuir fora do sistema AMI (risco de perder credenciamento; quebra de combinado com a AMI).
- Alternativas: ex-formador/diretor AMI aposentado ou desligado; guia AMI experiente; AMS/MACTE.
- Obra de Maria Montessori em domínio público no Brasil desde 2023; "Montessori" não é marca.
- Vídeo não substitui prática supervisionada, observação e estágio → modelo híbrido (vídeo grátis + laboratório presencial + observação).
- Perguntas abertas: o que é o SFEMP; faixa etária (0–3 / 3–6 / 6–12); público; orçamento.
